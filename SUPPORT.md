# Support

Scenario for Godot is an open-source editor plugin maintained by Scenario. This
page says where to look and whom to ask.

## Using the plugin

- Start with the [user guide](docs/USER_GUIDE.md), including
  [Troubleshooting](docs/USER_GUIDE.md#7-troubleshooting).
- For models, Creative Units and account settings, see the
  [Scenario Knowledge Base](https://help.scenario.com).
- For release changes, read the [changelog](CHANGELOG.md) and the
  [releases](https://github.com/scenario-labs/godot-plugin/releases);
  [known issues](BUGS.md) lists current limitations.

## Bugs, change requests and questions

Use the [issue chooser](https://github.com/scenario-labs/godot-plugin/issues/new/choose).
Search the [existing issues](https://github.com/scenario-labs/godot-plugin/issues)
first. For a question, open a blank issue with a title starting with "Question:".

Before filing a bug, collect:

- The Godot version (Help > About Godot), whether it is the standard or the
  .NET build, and your operating system.
- The plugin version from Project > Project Settings > Plugins, and whether you
  installed the release zip, the Godot Asset Library or a source copy.
- The lane, model and steps to reproduce, what you expected and what happened.
- Relevant lines from the editor's Output panel.

Public issues and attachments are visible to everyone. Never include an API key,
an API secret, a signed download URL or confidential project files.

## Account, billing, credits, API keys and security

Keep these matters out of public issues. Write to
[support@scenario.com](mailto:support@scenario.com) or use in-app support at
[app.scenario.com](https://app.scenario.com). Report security vulnerabilities as
described in [SECURITY.md](SECURITY.md).

## What to expect

Plugin issues are handled on a best-effort basis, without a response-time
commitment. Support for your Scenario account or subscription goes through the
Scenario channels above.
