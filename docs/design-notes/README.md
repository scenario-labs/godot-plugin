# Design notes

Proposals and open questions for the next releases. Planned work itself is tracked in [issues](https://github.com/scenario-labs/godot-plugin/issues) and [milestones](https://github.com/scenario-labs/godot-plugin/milestones). Each note is dated and states its status at the top: proposal, open question, decided, built or dropped. When a decision changes, a new note is added and the old one is kept.

| Date | Note | Status |
|---|---|---|
| 2026-10-04 | [Steps on any asset](2026-10-04-steps-on-any-asset.md): start from anything, take the steps you want, stop at the finish level you want | Proposal for 0.2 and later |
| 2026-10-04 | [Make me a game](2026-10-04-make-me-a-game.md): game kits, a coding agent, or a built-in code writer | Open question |
| 2026-10-16 | [Other engines](2026-10-16-other-engines.md): the same contract in Unity, then Unreal | Proposal |
