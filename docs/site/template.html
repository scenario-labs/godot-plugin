Install

  1. Download the zip and extract it at the root of your Godot project, so that addons/scenario/ sits next to project.godot.
  2. Enable the plugin in Project > Project Settings > Plugins.
  3. Paste a Scenario API key and secret into the Scenario dock, then press Connect.
